## 2024-05-09 - [Identifying Process Collection Bottleneck]
**Learning:** Found an O(N^2) or O(N * M) bottleneck in `ProcessPriorityManager.AdjustProcessPrioritiesAsync`. It gets all processes via `Process.GetProcesses()`, then for each process, it calls `exclusionList.Contains(process.ProcessName.ToLower())`. Since `exclusionList` is a `List<string>`, `Contains` does a linear scan for each process. Using a `HashSet<string>` with case-insensitive comparer makes this an O(1) lookup instead.
**Action:** Change `List<string> exclusionList` to `HashSet<string>` using `StringComparer.OrdinalIgnoreCase` in `ProcessPriorityManager` and `InitializeExclusionList()`.
## 2024-05-10 - [File Iteration Performance Optimization]
**Learning:** Found a memory and performance bottleneck in `AdvancedFileCompressionSystem.cs` where `Directory.GetFiles` was used to recursively search for files. `Directory.GetFiles` blocks and allocates an array containing all matching file paths, which consumes excessive memory and delays execution when scanning entire drives. Replacing it with `Directory.EnumerateFiles` lazily yields the paths. Combining this with `new EnumerationOptions { IgnoreInaccessible = true, RecurseSubdirectories = true }` also prevents `UnauthorizedAccessException` crashes on system folders.
**Action:** Prefer `Directory.EnumerateFiles` over `Directory.GetFiles` when traversing large directories or whole drives. Add `EnumerationOptions` with `IgnoreInaccessible = true` to gracefully handle restricted folders.
