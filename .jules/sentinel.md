## 2024-06-12 - [Path Hijacking in Process Recovery]
**Vulnerability:** The GPU optimizers were storing the raw process name (e.g., "nvidia-smi.exe") when killing a process, and later using that raw name in `Process.Start(new ProcessStartInfo(processName) { UseShellExecute = false })` to recover it.
**Learning:** Even with `UseShellExecute = false`, `Process.Start` without an absolute path will search the current working directory and `PATH` environment variable. An attacker could place a malicious executable with the same name in a writeable directory earlier in the PATH, leading to Local Privilege Escalation when the optimizer restarts the process.
**Prevention:** Always capture and store the absolute path (`process.MainModule?.FileName`) before terminating a process. Wrap the `MainModule` access in a `try-catch` for `Win32Exception` to handle processes that deny access, falling back securely or logging the failure.
