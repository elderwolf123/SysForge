## 2024-06-30 - Path Hijacking Vulnerability in Process Recovery Logic
**Vulnerability:** Critical Path Hijacking/Untrusted Search Path vulnerability in process recovery modules.
**Learning:** Process names (e.g. `nvidia-smi.exe`) were being used dynamically in `.Kill()` followed by storing just the name into a local state collection to be restarted later via `Process.Start()`. Because it was just the process name, restoring it could launch a malicious executable positioned earlier in the system's `PATH`. To resolve this securely, we must dynamically capture the absolute `ExecutablePath` of the exact process binary *before* killing it, keeping in mind that `Process.MainModule` access can throw `Win32Exception` (Access Denied for elevated/other-architecture processes) or `InvalidOperationException` (process has already exited), requiring safe fallback handling.
**Prevention:** Always secure the absolute system path of a process binary before terminating it if you intend to track, analyze, or restart that process later, and wrap module access in appropriate error handlers.
