## 2024-05-18 - Path Hijacking in GPU Optimizer Recovery
**Vulnerability:** The GPU optimizer classes stored a relative `processName` (e.g., `nvidia-smi.exe`) when terminating a process. When recovering it, they executed `Process.Start(processName)`, opening the application to Path Hijacking/Untrusted Search Path vulnerabilities where a local attacker could supply a malicious binary named identically in a prioritized directory.
**Learning:** This existed because the application erroneously assumed that the relative executable name it originally identified was inherently safe to execute later without qualifying the absolute original path it found.
**Prevention:** Always capture the process's absolute path via `MainModule.FileName` immediately before calling `process.Kill()`, and use this absolute path instead of just the executable name during recovery operations.
